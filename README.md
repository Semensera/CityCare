
# 🏙 CityCare

**CityCare** — це веб-сервіс для фіксації міських проблем (ями на дорогах, стихійні сміттєзвалища, проблеми з освітленням тощо) на інтерактивній карті. Проєкт створений для того, щоб зробити місто комфортнішим завдяки активній участі громадян.

## 🌟 Основний функціонал

- 🗺️ **Інтерактивна карта:** Перегляд усіх актуальних проблем міста у режимі реального часу (інтеграція з Leaflet.js).
- 📍 **Геолокація:** Автоматичне визначення поточного місцезнаходження користувача для швидкого додавання мітки.
- 📸 **Прикріплення фотографій:** Можливість додати фото проблеми (зберігається у форматі Base64).
- 🔐 **Авторизація та безпека:** Реєстрація та вхід користувачів із хешуванням паролів за допомогою Spring Security.
- 👥 **Система ролей:** - **Гість:** може лише переглядати карту.
  - **Користувач:** може переглядати карту та додавати нові проблеми.
  - **Адміністратор:** має повний доступ, включаючи видалення міток (перший зареєстрований користувач автоматично отримує цю роль).
- 💾 **Локальне збереження:** База даних не зникає після перезапуску сервера (дані зберігаються у папці `citycare_data`).

## 🛠 Технологічний стек

**Backend:**
- Java 17
- Spring Boot 3.2.2 (Spring Web, Spring Data JPA, Spring Security)
- H2 Database (File-based)
- Maven
- Lombok

**Frontend:**
- HTML5 / CSS3
- Vanilla JavaScript (Fetch API)
- [Leaflet.js](https://leafletjs.com/) (OpenStreetMap)

## 🚀 Як запустити проєкт локально

### 1. Вимоги
- Встановлена [Java 17](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html) або новіша.
- IDE (наприклад, IntelliJ IDEA, VS Code або Eclipse).
- Maven.

### 2. Запуск кроки:
1. Зробіть клон репозиторію на свій комп'ютер:
   ```bash
   git clone [https://github.com/ВашЛогін/CityCare.git](https://github.com/ВашЛогін/CityCare.git)
Відкрийте проєкт у вашій IDE.

Дочекайтеся завантаження залежностей Maven.

Запустіть головний клас CityCareApplication.java.

Відкрийте ваш улюблений браузер і перейдіть за адресою:

Plaintext
http://localhost:8080
📚 Інструкція з використання
Реєстрація Адміністратора: Найперший акаунт, який буде зареєстровано на сайті, автоматично отримує права Адміністратора (з'явиться кнопка видалення міток).

Додавання мітки: Увійдіть у свій акаунт, клікніть на будь-яке місце на карті (або натисніть "Знайти моє місцезнаходження"), заповніть форму зліва та натисніть "Відправити".

Перегляд бази даних: Консоль бази даних H2 доступна за адресою http://localhost:8080/h2-console (URL: jdbc:h2:file:./citycare_data/db, Username: sa, Password: пусто).

📂 Структура проєкту
/src/main/java/com/citycare/model — Entity-класи бази даних (User, Issue).

/src/main/java/com/citycare/repository — Інтерфейси для роботи з БД (Spring Data JPA).

/src/main/java/com/citycare/service — Бізнес-логіка та обробка даних авторизації.

/src/main/java/com/citycare/controller — REST API для обробки запитів від фронтенду.

/src/main/java/com/citycare/config — Налаштування безпеки Spring Security.

/src/main/resources/static — Фронтенд (HTML, CSS, JS).
